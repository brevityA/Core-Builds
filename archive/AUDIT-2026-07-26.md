# Audit — 2026-07-26

A full read-only audit of `brevityA/Core-Builds` (at `main`, commit `0ddab46`) and the
live site `brevitya.github.io/Core-Builds`, followed by fixes shipped as PRs. This file
is the durable record: what was found, why, and which PR resolves each item, so the
rationale travels with the code.

**Versions audited:** Template Suite `3.3.2` · Configurator `2.84.0` · min AIOStreams `2.31.1`
**After fixes:** Configurator `2.85` · Suite `3.4.0` (on the feature chain)

## Methodology
- Cloned the repo and ran the full local gauntlet: `node --test` (29), `pytest` (233),
  `node scripts/validate.mjs` (25), `validate_templates.py` (fleet), and a from-source
  rebuild of `configurator/index.html` (byte-identical to the committed build).
- Static analysis of `configurator/src/js/app.js` (6,260 lines) + data modules, the
  Cloudflare worker, the tools, and every workflow under `.github/workflows/`.
- Git archaeology on regressions (`git show`/diffs across PRs #554 / #557 / #577).
- Cross-checked `ROADMAP.md` vs `docs/roadmap.mdx` vs `CHANGELOG.md` vs
  `docs/changelog.mdx` vs `configurator/.../changelog.js` vs `versions.json` vs the live site.
- Competitive scan: Tam-Taro, TVFlix, Duck Tools/QuackStart, CrispyDuck, AIOStreams upstream.

The baseline was green (all suites pass). Every finding below was reproduced; every fix
is covered by a new test (regression test, golden snapshot, or e2e assertion).

## Roadmap review
Four records of "done/next" disagreed. Concretely: `ROADMAP.md` listed as *Planned* items
that had shipped (and two that shipped-then-removed in 3.2.8); `docs/changelog.mdx` was a
month behind the root changelog; `docs/whats-new.mdx` and the roadmap "Shipped" table were
hand-maintained and stopped being updated. The docs-auto-sync PR makes the *index* parts of
these pages regenerate from source (curated prose stays hand-edited inside
`<!-- AUTO:* -->` managed regions) and adds `tests/test_docs_generated.py`, which re-derives
each generated page and **fails CI if a committed page has drifted** — so the freeze cannot
recur silently (verified with a negative control).

## The two changelogs are independent tracks
The root `CHANGELOG.md` versions the **template suite** (now `3.x`); `changelog.js` versions
the **configurator** (`2.x`). The freeze happened because nothing mapped either into the
docs site. Going forward: suite releases flow through `sync-docs.yml` (which now also
announces to Discord); configurator releases flow through the regenerated `whats-new.mdx`.

## Competitive notes (what others do better)
- **Tam-Taro**: one canonical template + in-wizard customization = far less choice paralysis
  than our 41 active templates. Our own "tighter 6-template lineup" idea is the right call.
- **CrispyDuck**: drag-and-drop formatter builder with live preview — our biggest visible
  feature gap (we have 19 preset formatter strings + a gallery, but no live preview).
- **Where we lead**: automated validation, host-compatibility matrix, live instance status,
  diagnostics, device-specific capability profiles, and now golden-snapshot + drift-watch CI.
  The remaining gap is product surface, not engineering depth.
