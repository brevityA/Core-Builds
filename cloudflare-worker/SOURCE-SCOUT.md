# Source discovery notes and candidate triage

**Research snapshot:** 2026-10-26 (Sydney). This is a discovery inventory, not an endorsement or integration plan. Add-on directory descriptions are generally developer-submitted, and their manifest indicators are only page-level checks. A reachable manifest is not proof of accurate results, playback, rights, permission to forward content, or compatibility with Core Streams.

## Official-platform and live-channel route

- [RTVE Stremio addon source](https://github.com/Pigamer37/rtve-stremio-addon) is a third-party, unaffiliated project. Its README describes Spanish public broadcaster live TV/radio, RTVE Play search, metadata and streams; some results are explicitly external browser links. GitHub showed a commit on 2026-10-15 when fetched. This is evidence of an actively changed repository, not a guarantee of current deployment, rights, geoterritory, or Stremio playback.
- [World Live TV for Stremio](https://github.com/Kellogs12/world-live-tv-stremio) describes a self-hosted static multi-country live-TV collection with automatically updated channel URLs. Its README includes an Australia lineup and identifies some channels as official/free-to-air. The repository's own claim and an upstream URL are not enough to certify each channel stream's publisher, territory, or permission; review the actual endpoint and broadcaster terms per channel.
- [RTP Play](https://stremio-addons.net/addons/rtp-play) describes an unofficial adapter for RTP live TV/radio. Its listing says the RTP server requires a known User-Agent and the add-on sets one; no live stream playback was tested. Respect RTP's own geographic and terms restrictions—the adapter is not an RTP-affiliated project.
- [NexoTV](https://github.com/joaosavi/nexotv) is a third-party IPTV-to-Stremio project described in its README as accepting an Xtream panel, M3U playlist, or IPTV-org data. IPTV add-ons can mean either a user's authorized private playlist/account or a community-aggregated public list. Keep those cases separate; a public playlist does not itself establish authority to redistribute a channel.

For Australia, prioritize publisher-owned/free-to-air integrations that the broadcaster permits, and use each broadcaster's official availability and terms. A third-party Stremio adapter is not an endorsement or a bypass for region, login, ad, or device restrictions. The user-facing Stremio result list should link to the official platform rather than relay protected media unless the publisher explicitly permits direct stream distribution.

## Source-search tool

A reusable provenance-focused search tool is in [`../../tools/source-scout/README.md`](../../tools/source-scout/README.md). It uses Brave web search for broad web discovery and the public GitHub repository search API optionally. It labels index snippets as unverified leads, preserves source URLs and query provenance, exposes only returned GitHub repository metadata, and does not crawl pages or scrape media. It never claims rights, playback, manifest health, or independent corroboration. It requires the user to keep any Brave key local; no key or personal source URL is stored here.

## Next verification gates

Before adding any candidate as a Core Streams provider, collect and record (without private URLs or credentials):

1. Current first-party docs/repository and source ownership/terms.
2. Whether a user-owned account, cookie, API key, debrid, VPN, MediaFlow proxy, or personal profile is required—and whether the operator is authorized to share its results.
3. A generic, non-personal manifest contract and a minimal allowed test item, if the source supports one.
4. Actual Stremio stream response fields, timeout behavior, redirect behavior, and client playback evidence; distinguish each step in the report.
5. Item-level media rights/permission and applicable Australian/territory restrictions. If uncertain, leave it out.
6. Low-volume comparison with TorBox/debrid functions explicitly disabled where the purpose is TorBox-outage independence.

No deployment or Core Streams source integration was made from these discovery leads.
