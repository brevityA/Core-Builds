# Hybrid Templates

TorBox Pro + NZBGeek dual-source templates. Requires both a TorBox Pro subscription and an NZBGeek API key. Full documentation is in the [Template Directory](../README.md).

| Template | File |
|---|---|
| Core Nexus Hybrid | `core-nexus-hybrid.json` |
| Core Nexus Hybrid Lite | `core-nexus-hybrid-lite.json` |

> After importing, go to **Add-ons → Newznab** and enter your NZBGeek API key.
