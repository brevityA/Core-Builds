# Flash Templates

Cached-only instant play templates. `excludeUncached: true` — only streams already cached in TorBox appear. Full documentation is in the [Template Directory](../README.md).

| Template | File |
|---|---|
| Core Nexus Flash | `core-nexus-flash.json` |
| Core Nexus Flash 4K | `core-nexus-flash-4k.json` |

> Flash templates have no Lite variants — they are already minimal by design.
