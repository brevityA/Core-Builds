## 🔧 What's Inside Every Template

| Feature | Detail |
|---|---|
| **Filtering** | 24 ESEs (20 Tamtaro standard + 4 CB kills) · 6 ISEs |
| **Sorting** | cached → matched → score → resolution → quality → audio |
| **Deduplication** | filename + infoHash + smartDetect · libraryBehaviour: prefer |
| **Matching** | titleMatching contains/0.75 · yearMatching ±2yr · seasonEpisode non-strict |
| **Auto features** | autoPlay · precacheNextEpisode · preloadStreams · dynamicAddonFetching |
