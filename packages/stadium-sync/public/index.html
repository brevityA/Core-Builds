Daktronics All Sport 500019200 8N1 RTD, frames 0x16 to 0x17. UDP the bytes to the port in the config, or POST the raw frame to /api/ingest/main/rtd.
Sportzcast / ScoreLinkPOST the JSON contract to /api/ingest/main?format=sportzcast. A local ScoreConnect on port 1402 can be set as sportzcast.host.
Anything elsePOST guest, home, guestScore, homeScore, clock, period, running. Fair-Play, OES, Nevco, or a school app.
