# Nuvio stack — Essential

One profile. 1080p. Universal badges. First install.

1. Nuvio → create one profile.
2. Build the stream engine in the [Core Builds Configurator](https://brevitya.github.io/Core-Builds/configurator/) — **Core Stable 1080p** or **Essential**.
3. Install that manifest in Nuvio → Addons → Add by URL.
4. Paste the badge pack:

```
https://raw.githubusercontent.com/brevityA/Core-Builds/refs/heads/main/tools/badges/published/core-neon-universal.json
```

Settings → Streams → Fusion badge URLs → Import.

5. Add OpenSubtitles if you want them. Done.

Does not install addons for you. Does not need AIO Enhanced.
