# Nuvio stack — Anime

SeaDex-first. Japanese audio. Dual-audio fallback.

1. One Nuvio profile named **Anime** (keep it off the kids profile).
2. Configurator → **Core Nexus Anime** (or Anime 4K / Anime Dub).
3. Install that manifest first, then catalogs you already trust (AniList if you use it).
4. Badge pack:

```
https://raw.githubusercontent.com/brevityA/Core-Builds/refs/heads/main/tools/badges/published/core-neon-universal.json
```

Universal mode reads SeaDex / dual-audio / JP audio from the filename. AIO Enhanced is optional if the anime template already emits parsed fields.

5. English-dub house: use **Anime Dub** in the Configurator instead of flipping badges.
