# Nuvio stack — Pro

4K-capable TV. TorBox Pro / Apex. AIO Enhanced badges.

1. Two Nuvio profiles if the house mixes a 4K TV and a stick: **House 4K** and **House 1080**.
2. Configurator → **4K Apex** (or Samsung TV 4K if the panel hates Dolby Vision).
3. Install the 4K manifest on the TV profile. Install **Stream** / **Essential** on the stick profile.
4. Badge pack on the 4K profile:

```
https://raw.githubusercontent.com/brevityA/Core-Builds/refs/heads/main/tools/badges/published/core-neon-enhanced.json
```

Open the [Badge Builder](https://brevitya.github.io/Core-Builds/tools/badges/), keep AIO Enhanced + Core Neon, then **Open in Core Configurator** so the companion formatter rides with the template.

5. If the TV is Samsung / TCL / no DV, use the No-DV pack instead:

```
https://raw.githubusercontent.com/brevityA/Core-Builds/refs/heads/main/tools/badges/published/core-nodv-universal.json
```
