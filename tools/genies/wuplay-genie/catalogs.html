official import helper

Prepare a WuPlay import file

Choose a data export you downloaded from WuPlay's official configurator. Genie edits a local copy of that file, preserves unknown fields, and downloads a new file for you to upload in the official Import Data screen. Nothing is uploaded by Genie and no profile key is needed here.

Important: WuPlay's import flow can replace existing data categories. Keep the original export as a backup and review the change report before downloading the modified file. Missing catalogs or screens are never fabricated; they remain guided.
The downloaded file is generated locally. Genie removes profile keys and bearer-token fields from the generated copy. If the current WuPlay importer requires a source key, stop and use the untouched official export in WuPlay instead.
