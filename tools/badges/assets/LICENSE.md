## Stable file names

Installed Nuvio packs load these images by URL, so a file here is never
renamed or deleted once published. A changed design keeps its file name; a
retired badge keeps its file. `tests/test_official_badge_packs.py` fails if a
file listed in `../published/badges.json` goes missing.
