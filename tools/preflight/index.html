layer 1 · static audit

Drop in a config. Get the truth.

Template or live user-config both work (a {"config":…} wrapper is auto-unwrapped). All checks run in this tab; every rule cites the real rejection it encodes.

layer 2 · live

Dry-run it on the actual host.

Sends the redacted config to the chosen instance as a throwaway user with a generated password. The instance's own validator answers: accepted (then we read the manifest back to prove the write landed whole), or the precise rejection ladder. No delete is exposed publicly — the inert leftover is a fixture-grade artifact of every dry-run on that host.
