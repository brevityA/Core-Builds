What's new

🆕 What's New — v3.51

↗Full Configurator changelog →  ·  suite changelog →
v3.51 · Nov 26 2026
NEWChoose what Full stack hides in Cinemeta — Quick install's Full stack option now lists Search, Home rows and Details pages. Search and Home rows are on by default; hide Details pages too if you want AIOMetadata to show every title's details.
NEWOptional MDBList and RPDB keys — add an MDBList key for its ratings and lists, or an RPDB key for rating badges on posters. They are saved in this browser and sent only to AIOMetadata, inside the new config; they are never part of a share link.
NEWRestore the original Cinemeta — one button puts Stremio's own Cinemeta back on your account, with its rows, search and details.
NEWFull stack never adds a second AIOMetadata — if one you set up elsewhere appears while Full stack is saving, that one is used.
v3.50 · Nov 26 2026
NEWInstall to Jellyfin — Quick install has a Jellyfin target. AIOStreams can act as a Jellyfin server, so after saving you get a server address, a username (your config ID) and your config password to sign in with from a Jellyfin app.
NEWJellyfin picks a host that has it turned on — ElfHosted has AIOStreams' Jellyfin server switched off, so a Jellyfin install goes to a public host that has it on (checked on every host on Nov 26). A custom host is used as you set it.
NEWHide HDR — a new Fine-Tune toggle under Video Preferences for screens that only show SDR. It hides HDR10, HDR10+, HLG and Dolby Vision streams; SDR and untagged streams stay. It works on every output profile and survives a re-import.
NEWGenerated output unchanged — every reference config is byte-for-byte what 3.49 produced apart from the version stamp. Hide HDR is off unless you turn it on, and Jellyfin uses the same config as any other target.
v3.49 · Nov 26 2026
NEWFull stack now sets AIOMetadata up properly — Quick install used to add AIOMetadata's bare address, which has no settings and so shows no rows, no search and no details. It now creates an AIOMetadata config on the public ElfHosted instance with its own default providers, protected by the same password as your AIOStreams config, and installs that. An empty AIOMetadata from an earlier install is swapped out; one you set up yourself is kept.
NEWThe Cinemeta patch works again — it went to a Cinebye address that no longer exists, so Cinemeta was never patched. Full stack now hides Cinemeta's home rows and search in your Stremio account itself, from your browser. Cinemeta still supplies details, notifications and the calendar.
NEWCinemeta is only patched once AIOMetadata is in place — if AIOMetadata cannot be set up, Cinemeta is left as it is, so your home screen and search never end up empty.
NEWGenerated output unchanged — every reference config is byte-for-byte what 3.48 produced apart from the version stamp. This release changes what Full stack does on your Stremio account, not the AIOStreams config.
v3.48 · Nov 26 2026
NEWReady to play first replaces hard cached-only — 3.47 made Quick install's Balanced hide every stream your service would still have to download. AIOStreams removes those even when nothing else is left, so a brand-new episode or a rarer title could show no streams at all (checked in AIOStreams 2.36.0). Fast and Balanced now show only streams that play straight away while there are any, and the ones that need downloading when there are none, among streams that pass your other settings such as picture quality.
NEWFast behaves the same way — Fast hid uncached streams outright before 3.48 too; it now uses Ready to play first as well.
NEWReady first is also in the full builder — Streams shown offers Mixed, Ready first, Cached only and Uncached only, and the CLI takes --cache-mode ready. Cached only still hides downloads even when nothing else is ready.
NEWA Cached only pick from 3.47 is explained — if you chose Cached only in Quick install, it is kept and the screen says what it does; choose Ready to play to switch.
🔧 Built-in tools (inside the Builder)

These tools live inside the Template Builder. Open the Builder to use them:

Health ScoreReview step — 0–100 score with 11 checks and letter grade
TroubleshooterReview step → Tools — interactive decision tree for common issues
Stream TestManifest modal → "Test streams" — fetches real streams to verify your config
CompareSplash page → Compare — side-by-side template diff (presets, ESEs, PSEs, sort)
DiagnosticsFooter → Report Issue — sanitized config dump safe for GitHub issues
Backup HistoryReview step — 20-entry local backup timeline with restore
Host CompatReview step — checks elfhosted/fortheweak/self-hosted compatibility
PreflightInstall step — checks credentials, device mismatches, missing guards before deploy
