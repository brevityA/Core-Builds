# v3.14 live import checklist

A 15-minute end-to-end check before announcing v3.14. Use a **throwaway**
AIOStreams config: do not overwrite your real one.

## What you import

The test templates are the v3.14 golden configs: the exact output the
configurator generates, with every credential field empty. Import by URL in
AIOStreams → Save & Install → Import → Import Template:

These URLs read from the PR branch so the check can run before merge. Once
v3.14 is merged, replace `fix/balanced-profile-restore` with `main` in each.

| Test | Template URL |
|---|---|
| A — TorBox 1080p (default) | `https://raw.githubusercontent.com/brevityA/Core-Builds/refs/heads/fix/balanced-profile-restore/configurator/e2e/golden/torbox-1080p-standard.json` |
| B — TorBox 4K (default) | `https://raw.githubusercontent.com/brevityA/Core-Builds/refs/heads/fix/balanced-profile-restore/configurator/e2e/golden/torbox-4k-standard.json` |
| C — P2P 1080p | `https://raw.githubusercontent.com/brevityA/Core-Builds/refs/heads/fix/balanced-profile-restore/configurator/e2e/golden/p2p-1080p.json` |

Recommended host: ElfHosted (strictest regex allowlist). Every pattern in
these templates was checked against all eight registered hosts' live
allowlists on 2026-10-02: 0 rejections.

## Checks

For A and B, enter a TorBox API key in Services after loading. For D, enter
EasyNews credentials. C needs none.

1. **Save succeeds** for all four. A refusal here is the release blocker this
   checklist exists to catch: note the exact error text.
   - C and D are the important ones: before v3.14 an enabled EZTV / Torrent
     Galaxy / Knaben / Zilean with no debrid service refused the whole save.
2. **Scrapers (A, B):** Installed Addons lists StremThru Torz, Meteor, Comet,
   **MediaFusion, EZTV, Torrent Galaxy, Zilean, Knaben** (plus Library,
   SeaDex, subtitles, TMDB). C and D must **not** list EZTV, Torrent Galaxy,
   Zilean or Knaben.
3. **Regex (A, B):** Filters → Regex shows ranked patterns (79 at 1080p, 83 at
   4K) and the excluded patterns (Upscaled, BR-DISK, Extras…). Save does not
   say "regex not allowed".
4. **4K sorting (B):** open a popular 4K movie with both cached and uncached
   2160p results. The top results are **cached (⚡) 2160p**; an uncached (⏳)
   2160p REMUX must not sit above a cached 2160p WEB-DL. All 2160p still above
   all 1080p.
5. **Series split (A):** open a TV episode with uncached results. Cached
   episodes first; among the uncached ones, higher-seeder results rank above
   lower ones.
6. **Sort list (A, B):** Sorting shows no `Audio Channel` entry.
7. **Configurator page:** open the live configurator after merge, hard-reload
   once; the version badge reads 3.14.
8. **Updating keeps your setup:** in the configurator, import a config that has
   one extra scraper you added yourself (for example a Newznab indexer), click
   update, then Cancel. Nothing changes. Update again and confirm: the extra
   scraper is still there in the preview and in the downloaded JSON. Undo puts
   the previous setup back.
9. **Anime:** build a TorBox config with content set to Anime; the preset list
   includes AnimeTosho. A P2P build with Anime content saves without error.
10. **Retired add-ons are gone:** the Extras list has no TorBox (addon), USA TV,
    Debridio Watchtower, Knaben or Zilean cards, and Fine-Tune has no Age Rating
    Limit.

Checks 8–10 run in the configurator itself (after #779, #778 and #776 merge),
not by importing the golden URLs above.

Report back with pass/fail per numbered check and the error text for any
failure. Do not paste API keys, manifest URLs or UUIDs.
