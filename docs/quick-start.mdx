The **Configurator Quick Install** route is the recommended way to start. It supports multiple providers, chooses a compatible AIOStreams host, validates the generated configuration, and can return a manifest URL or perform a direct Stremio install.

<Card title="Open Core Builds Configurator" icon="bolt" href="https://brevitya.github.io/Core-Builds/">
  Choose **Quick Install** on the opening screen.
</Card>

<Steps>
  <Step title="Choose where you watch">
    Select Stremio, WuPlay, Nuvio, or manifest output. For Stremio, leaving the login fields blank returns a manifest URL instead of sending a direct-install request.
  </Step>

  <Step title="Choose one or more providers">
    Select TorBox, Real-Debrid, AllDebrid, Premiumize, EasyNews, or Free/P2P. Use **Additional services & scrapers** for optional services and indexers.
  </Step>

  <Step title="Enter the credentials you use">
    Each selected paid provider displays its required credential fields and a **Get key** or **Open account** link. Free/P2P sources do not require a key.

    Expand **TMDB metadata — optional** to add either a TMDB Read Access Token or API Key. TMDB improves title/year matching and digital-release filtering. Without it, Core Builds disables every TMDB-dependent feature so AIOStreams still accepts the configuration.
  </Step>

  <Step title="Choose a performance profile">
    - **Fast:** 1080p, cached-first, smaller files
    - **Balanced:** 4K with a sensible pool and 30 GB cap
    - **Maximum:** 4K, largest pool, quality-first
  </Step>

  <Step title="Create and install">
    Select **Create & Install**. Core Builds validates the generated configuration, selects a compatible AIOStreams host, and opens the appropriate install instructions or result.
  </Step>
</Steps>

<Info>
  **Privacy and network behaviour:** Export JSON creates the configuration locally. Direct Install sends the generated configuration to the selected AIOStreams host. A direct Stremio installation sends the supplied Stremio login details to the Stremio API for that operation. Core Builds does not claim that no data is transmitted.
</Info>

## Manual import

Manual import remains available for advanced users and recovery:

1. Choose a template from the [Template Directory](/template-directory).
2. Open a compatible host (guidance: [Instance Status](/instance-status); live check: the configurator's **Tools → Preflight**).
3. Import the template's raw JSON URL.
4. Add provider credentials in AIOStreams.
5. Review the configuration and install its manifest.
