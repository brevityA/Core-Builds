All templates require **AIOStreams v2.32+**. Each section has a **Lite** tab for lower-overhead setups.

<Note>
  **Quick import:** click an Import button (or a host under **Also on**) to open the template in that AIOStreams instance, then follow its prompts. Hosts below AIOStreams 2.36 aren't listed. To use your own instance, copy the raw URL and paste it under **About → Get Started → Load Template**.

  **ElfHosted** may refuse a template's regex with "Forbidden URL" unless the instance trusts Core Builds. If that happens, use another host.
</Note>

<Warning>
  **A TMDB Read Access Token is required for templates to work correctly.** Without it, title matching falls back to AIOStreams defaults — foreign titles, anime, and anything with multiple versions will match poorly or return no results.

  Get yours free at [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api) → **Read Access Token** → paste into AIOStreams → **Settings → TMDB Access Token**.
</Warning>

## Start here: Core Builds

One template for every device and service. AIOStreams asks what you watch on, the picture you want, what matters most, whether to show only streams that play straight away, your language and whether you mostly watch anime; then you pick your service: TorBox, Real-Debrid, AllDebrid, Premiumize, Debrid-Link, Offcloud, EasyDebrid, PikPak, Seedr, Debrider or EasyNews, or none for free P2P. You get the same setup the [configurator's Quick install](https://brevitya.github.io/Core-Builds/configurator/) would build for those answers. For Debridio, Usenet indexers or HTTP streams, use the configurator instead.

Free P2P needs a host that allows it: ElfHosted refuses P2P, so import on Yeb's / ForTheWeak or a host under **Also on**.
