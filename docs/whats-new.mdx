## Configurator v3.39 (Nov 21 2026)

## Configurator v3.38 (Nov 21 2026)

<CardGroup cols={2}>
  <Card title="Fine-Tune opens without a freeze" icon="sparkles">
    it now opens with only the section you are heading to in the page and adds the rest just after it appears. On a phone simulated at a quarter of desktop speed, the longest freeze when opening it from Quick install, or straight at Stream cards, fell from 124–133 ms in 3.36 (94 ms in 3.37) to under 50 ms, the point where frames start to drop (median of 10 runs). Opening Quick install itself still takes about the same as in 3.36, around 55 ms.
  </Card>
  <Card title="Share link with a QR code" icon="bolt">
    Share Link in Export & share now also shows a QR code to scan on another device and the link itself, ready to copy. If the browser refuses the copy, the link is selected on screen and a message says so; before, nothing happened. The link still carries settings only, never keys or passwords.
  </Card>
  <Card title="Generated output unchanged" icon="shield-check">
    every reference config is byte-for-byte what 3.37 produced apart from the version stamp; only Fine-Tune opening and the share link changed.
  </Card>
</CardGroup>

## Configurator v3.37 (Nov 20 2026)

<CardGroup cols={2}>
  <Card title="Review without folded panels" icon="sparkles">
    Review used to hide most of its settings in nine folded panels, three of them inside another, and the Install button sat in the middle of them. Install is now always on the page, with Test streams first under it. Four rows below it each open one panel that slides up over Review: Your AIOStreams (host, password and config ID, an already-have-a-manifest field, and Base config at the bottom, marked optional), Stream cards (the picker, Compare side by side, the score display and What this build does), Checks (the health score and host compatibility, summed up on the row) and Export & share (JSON file, Copy JSON with the JSON preview, share link and import link). The Stream cards row shows a small live card. Done, Escape, tapping outside and the phone’s Back all close a panel and return you to the row you opened it from. On a phone, the old Review with every panel open was 7,942 px tall; the new one is 2,550 px.
  </Card>
  <Card title="Tools moved to the menu" icon="bolt">
    the Troubleshooter, Copy a safe feedback report and Recommended add-ons are now under Menu › Help, each with its own link (…/configurator/#troubleshooter, #feedback, #stack). Menu › Import a config opens Your AIOStreams with the cursor in the manifest field.
  </Card>
  <Card title="Smoother panels on phones" icon="shield-check">
    Fine-Tune lays out only the sections on screen when it opens, and the rest as you scroll near them. On a phone simulated at a quarter of desktop speed, the longest freeze when opening it from Quick install fell from 133 ms to 94 ms (median of 10 runs). Fine-Tune, Quick install and the Review panels now move with the same 200 ms motion, and Reduce Motion makes all of them instant. Phones show solid panels instead of frosted glass, which re-blurred the page behind on every scroll frame; desktop keeps the glass. Hover and selection effects animate only colour, opacity and movement, never size.
  </Card>
  <Card title="Generated output unchanged" icon="sliders">
    every reference config is byte-for-byte what 3.36 produced apart from the version stamp; only the Review screen, the menu and animations changed.
  </Card>
</CardGroup>
