## Configurator v3.51 (Nov 26 2026)

## Configurator v3.50 (Nov 26 2026)

<CardGroup cols={2}>
  <Card title="Install to Jellyfin" icon="sparkles">
    Quick install has a Jellyfin target. AIOStreams can act as a Jellyfin server, so after saving you get a server address, a username (your config ID) and your config password to sign in with from a Jellyfin app.
  </Card>
  <Card title="Jellyfin picks a host that has it turned on" icon="bolt">
    ElfHosted has AIOStreams' Jellyfin server switched off, so a Jellyfin install goes to a public host that has it on (checked on every host on Nov 26). A custom host is used as you set it.
  </Card>
  <Card title="Hide HDR" icon="shield-check">
    a new Fine-Tune toggle under Video Preferences for screens that only show SDR. It hides HDR10, HDR10+, HLG and Dolby Vision streams; SDR and untagged streams stay. It works on every output profile and survives a re-import.
  </Card>
  <Card title="Generated output unchanged" icon="sliders">
    every reference config is byte-for-byte what 3.49 produced apart from the version stamp. Hide HDR is off unless you turn it on, and Jellyfin uses the same config as any other target.
  </Card>
</CardGroup>
