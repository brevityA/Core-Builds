# What's New in the Configurator

This page is regenerated from `configurator/src/data/changelog.js` by `scripts/sync-docs.py`, so it always reflects the latest shipped configurator version (currently **v3.36**).

For the template-suite release log, see the [Changelog](https://corebuilds-docs.docsalot.dev/changelog).

## Configurator v3.36 (Nov 19 2026)

<CardGroup cols={2}>
  <Card title="Update my setup saves again" icon="sparkles">
    saving always failed with “Not saved. Not Found”: the configurator sent an update request AIOStreams does not have. It now uses the one AIOStreams provides (2.32 and later), so the update lands on your existing config and your Stremio link keeps working.
  </Card>
  <Card title="Reinstalling keeps the same config" icon="bolt">
    Get Install Link with a saved UUID ran into the same failed update and quietly created a new config, so each reinstall gave you a new Stremio link. It now updates the config you have; the link it shows carries the encrypted password AIOStreams expects.
  </Card>
  <Card title="Full-stack install signs in properly" icon="shield-check">
    after adding AIOStreams to Stremio, the AIOMetadata install, the Cinemeta patch and the addon reorder ran without your Stremio session, and “Already installed” never showed. They now use the session, and AIOMetadata is never added on top of an addon list that failed to load.
  </Card>
  <Card title="Stream cards that printed code" icon="sliders">
    Family v3 showed template text in place of the title, and Omni Diamond printed an “invalid expression” on every stream. Both are fixed, and the DD+ badge in Omni Diamond, Zenith Diamond, Auburn Tiger, Midnight Slate and RB3 now shows on DD+ streams (it never matched before). Previews also show the stream’s language again.
  </Card>
  <Card title="Quick install stays in Quick install" icon="gauge">
    How results look, the rows under Defaults we’ll use and Customize every setting used to leave Quick install for the full builder, with its own menu, and open Fine-Tune there. Fine-Tune now opens over Quick install, and closing it (or pressing Back) takes you straight back with your choices and anything you changed in Fine-Tune.
  </Card>
  <Card title="Tool pages on phones" icon="wand">
    the WuPlay Genie header no longer wraps its tagline, Template Inspector’s Import JSON File is a proper button and its hint text shows line breaks, and Account Tools drops the buttons the site menu already covers.
  </Card>
  <Card title="Generated output unchanged" icon="layers">
    all 20 reference configs are byte-for-byte what 3.35 produced apart from the version stamp. Only a build that uses Family v3, Omni Diamond, Zenith Diamond, Auburn Tiger, Midnight Slate or RB3 changes, and only in that stream-card text.
  </Card>
</CardGroup>

## Configurator v3.35 (Nov 18 2026)

<CardGroup cols={2}>
  <Card title="A menu on every other page" icon="sparkles">
    a Menu button opens the same list everywhere except the main page: Build (main page, Quick install, Custom build, Guided setup, update, import), Tools, Help (what’s new, the tour, Report an issue, Support) and Community (docs, Reddit, Discord, GitHub). In the configurator it sits at the start of the header, so it never covers the Continue bar; on the tool pages it is in the bottom-left corner.   </Card>
  <Card title="Stream cards easier to find" icon="bolt">
    the stream-card picker (the formatter) now has a row in Quick install’s step 3, a Stream cards button on Custom build’s first step, a Stream cards row on Review outside the folded panels, an entry in the menu and its own link (…/configurator/#cards). Each opens the picker directly; before, it sat inside a folded panel on Review or four sections down Fine-Tune.
  </Card>
  <Card title="A cleaner stream-card picker" icon="shield-check">
    one large preview of the selected style sits on top, with every style below as a plain row: name, one-line description and a tag, in the main page’s look. Before, each style was a card with its own small preview in a sideways strip, and only two and a half fitted on screen. An imported formatter now says it has no preview instead of showing Family v4’s.
  </Card>
  <Card title="Compare stream cards side by side" icon="sliders">
    under the stream-card picker, Compare side by side shows the same sample stream in up to three formatters at once, laid out as a phone list or as TV rows, for a cached 4K REMUX, a cached 1080p WEB-DL or a 4K stream that is not cached, with a Use this button on each. Every card preview is now rendered by AIOStreams’ own formatter engine instead of a hand-made illustration.
  </Card>
  <Card title="Fine-Tune, tidied" icon="gauge">
    section labels, the title and the help marks now match the main page, a row of section chips (Profile, Stream cards, Sound, Video, Subtitles, Catalogs, More) stays pinned under the header and follows your place as you scroll, Stream cards moved up to second, and the light theme no longer shows white titles on a white panel. The header itself stays put now; it used to scroll away.
  </Card>
  <Card title="Tool pages, closer to the main page" icon="wand">
    the menu now opens light or dark to match the page it is on (it went light on dark pages), and leaves room at the bottom so it no longer covers the last row. Template Inspector and Account Tools get the same title and label as the other tools, the All Core Tools page swaps its bright banner for the main page’s outlined row, and on phones the Genie, Nuvio, WuPlay and Preflight headers stop squeezing their names into a narrow column. Banner Studio shows its tour on a first visit instead of the tour and the changelog at once.
  </Card>
  <Card title="Quick install heading on phones" icon="layers">
    the large Core Builds heading stayed pinned while you scrolled, so every step slid underneath it. It now scrolls away with the page.
  </Card>
  <Card title="Stream cards from the keyboard" icon="bug">
    the cards can be reached with Tab and picked with Enter or Space, and the score display choices in Review and Fine-Tune no longer clear each other when both are open.
  </Card>
  <Card title="Generated output unchanged" icon="sparkles">
    every config the configurator and the CLI build is byte-for-byte what 3.34 produced apart from the version stamp; only navigation and the settings screens changed.
  </Card>

## Configurator v3.34 (Nov 18 2026)

<CardGroup cols={2}>
  <Card title="Three new stream cards" icon="sparkles">
    Core Compact (two short lines: cache, resolution and service, then quality, size, audio and language), Core Detailed (up to six lines with title and episode, bitrate, subtitles, release group, source and file name) and Core Badges (the same facts as [TEXT LABELS]). Missing details are left out instead of shown as Unknown, empty brackets or a stray ·, and a result whose cache state AIOStreams does not know gets no icon rather than a guess.
  </Card>
  <Card title="Score display" icon="bolt">
    the Core cards can show the stream score as ★ 87, in plain or bold-looking digits (Unicode characters, not font weight; a player without them shows boxes), or hide it. The score only exists with the Advanced and Labs profiles, and the setting says so.
  </Card>
  <Card title="Previews rendered by AIOStreams" icon="shield-check">
    the Core cards are previewed with AIOStreams’ own formatter engine at the pinned release, and tests render every style through it for complete, sparse, P2P, episode, season-pack and long Unicode streams. Other cards are labelled illustrative.
  </Card>
  <Card title="Generated output unchanged" icon="sliders">
    every config the configurator and the CLI build from existing settings is byte-for-byte what 3.33 produced apart from the version stamp; only choosing one of the new cards changes the formatter.
  </Card>
</CardGroup>

## Configurator v3.33 (Nov 18 2026)

<CardGroup cols={2}>
  <Card title="A one-screen main page" icon="sparkles">
    the Core mark, the Core Builds name and the version, then six equal rows: Core Builds (opens Quick install), Template Inspector, Back Up Addons, Nuvio Stack Genie, Core Badge Builder and All Core Tools. Each row has a hexagon icon and a short tag saying what it is.
  </Card>
  <Card title="Support and shortcuts" icon="bolt">
    a Support Core Builds button sits under the rows, and Custom build, Guided setup, update, import, the tour, template compare, what’s new and Report an issue are one tap away on All Core Tools. Each also has its own link (for example …/configurator/#advanced), and the links now work while the page is open as well as on first load.
  </Card>
  <Card title="Smooth page changes" icon="shield-check">
    moving between the configurator and the tool pages cross-fades instead of flashing white, the main page’s rows rise in, and Quick install glides up. All of it switches off when your device asks for reduced motion.
  </Card>
  <Card title="Quick install, redesigned" icon="sliders">
    three labelled steps: where to install, your service, and your preferences. Apps and services are full-width rows with logos from the Core Builds Icon Pack; what matters most and streams shown are one-tap switches. On a computer your build summary and the Install button stay pinned on the right.
  </Card>
  <Card title="Delivery up front" icon="gauge">
    Direct Install, Manifest URL or Raw JSON is the first switch in Quick install, so you can export the template file without signing in to Stremio or contacting a host. Device, resolution, connection speed, template profile, language, Full stack, Clean reinstall and TMDB sit under Options & defaults.
  </Card>
  <Card title="Every install target kept" icon="wand">
    Stremio, Nuvio, WuPlay, Chillio and Other app all stay in Quick install, on the Review screen and in the manifest window, and the Nuvio Stack Genie still hands off into Nuvio.
  </Card>
  <Card title="Install progress you can trust" icon="layers">
    a progress window ticks each step (host check, regex check, save, install) only after it finishes, and marks a check it could not run as not verified. The last step names your target: Stremio, or your install link for every other app.
  </Card>
  <Card title="Paste and show buttons on key fields" icon="bug">
    every provider key, TMDB and manifest field gets a Paste button and a show or hide toggle. Connection speed has 25, 50, 100 and 250 Mbps presets, and the bitrate cap stays at 80% of it.
  </Card>
  <Card title="A better message form" icon="sparkles">
    pick Problem, Idea, Question or Thanks and the form says what to include, with a Start with a template button that fills in an outline. Your name is optional, the setup details it attaches are shown with a switch to leave them out (never keys or passwords), and a draft survives closing the panel. If a message cannot be sent you see why, and get Copy message, Discord and GitHub issue buttons so nothing is lost.
  </Card>
  <Card title="Feedback carries your current setup" icon="bolt">
    the message form attached setup details from your last saved state instead of the build on screen; it now reads the live one.
  </Card>
  <Card title="All Core Tools, regrouped" icon="shield-check">
    the tools page leads with the Template Builder, then configurator shortcuts, AIOStreams, Genies, Stremio account, and Speed & media, one row per tool. Stream card previews, what’s new and the built-in tools list fold away. Its Health Score and Troubleshooter links used to land on the plain main page because the site’s redirect dropped the link’s target; they now open the right screen.
  </Card>
  <Card title="Usage statistics are opt-in" icon="sliders">
    page visits and downloads are counted only after you tick the box on Review or in Quick install; it starts unticked and never sends keys, account names or your configuration. (#839)
  </Card>
  <Card title="H.264 10-bit regex accepted again" icon="gauge">
    restricted hosts such as ElfHosted refused every save because the H.264 10-bit pattern no longer matched their allowlist word for word after Vidhin05 rewrote it; the regex is re-synced from upstream. (#838)
  </Card>
  <Card title="Samsung TV 4K saves accepted again" icon="wand">
    the same allowlist drift refused Samsung TV 4K setups on restricted hosts; the regex snapshot is re-pinned to upstream. (#822)
  </Card>
  <Card title="DV-Only Kill removes only Dolby Vision-only releases" icon="layers">
    on Samsung, Fire Stick HD, Roku, projectors and other devices without Dolby Vision, the rule had its arguments reversed and removed the HDR10, HDR10+, HLG and SDR streams that lacked DV. It now removes only DV-only releases, and runs before the rules that count streams. (#841)
  </Card>
  <Card title="Elite REMUX pins work again" icon="bug">
    the 4K and 1080p elite REMUX pins asked for the wrong field in each filter and matched nothing; FraMeSToR-class REMUXes are pinned to the top again. (#841)
  </Card>
  <Card title="Bad 1080P Bluray limited to new movies" icon="sparkles">
    the rule now applies only in a movie’s first 90 days, so older movies keep the 1080p Bluray encodes it used to remove. Other quality filters are unchanged. (#841)
  </Card>
  <Card title="Titles named “AI” are no longer filtered out" icon="bolt">
    the AI-upscale exclusion now needs an upscale word such as Upscaled or Enhanced. Restricted hosts accept only the original allowlisted pattern, so there the original is swapped in rather than dropped. (#841)
  </Card>
  <Card title="Generated output unchanged" icon="shield-check">
    this release adds no config change of its own; the config changes since 3.32 are the four stream-selection fixes and two regex re-syncs listed above, already on the main branch.
  </Card>
</CardGroup>
