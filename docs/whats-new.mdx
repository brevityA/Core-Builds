This page is regenerated from `configurator/src/data/changelog.js` by `scripts/sync-docs.py`, so it always reflects the latest shipped configurator version (currently **v3.25**).

For the template-suite release log, see the [Changelog](https://corebuilds-docs.docsalot.dev/changelog).

## Configurator v3.25 (Oct 29 2026)

<CardGroup cols={2}>
  <Card title="EasyNews add-ons now reach your config" icon="sparkles">
    choosing EasyNews or EasyNews+ under Additional services & scrapers on a TorBox (or any non-EasyNews) build left them out of the JSON, because both need the EasyNews service and that dialog had no way to add it. Picking either now adds the EasyNews service too, and Quick install asks for its username and password. Unticking them takes the service back out of Quick install.
  </Card>
  <Card title="Typing no longer jumps to the previous box" icon="bolt">
    a helper that selects a field’s text 50 ms after you click into it also moved the cursor back there, so autofill, a password manager or fast tabbing could put the next field’s text in the wrong box. In Quick install the Stremio password could end up in the email field and the install would sit waiting.
  </Card>
  <Card title="Generated output unchanged" icon="shield-check">
    for the same settings, every config the configurator and the CLI build is byte-for-byte what 3.24 produced apart from the version stamp; the fix changes which settings the EasyNews picks produce.
  </Card>
</CardGroup>

## Configurator v3.24 (Oct 26 2026)

<CardGroup cols={2}>
  <Card title="Chillio is a first-class install target" icon="sparkles">
    Review & Install and Quick install now offer Chillio alongside WuPlay and Nuvio. The manifest modal gains a Chillio tab that builds the ChillLink URL (your host’s /chilllink/uuid/password route, which every public AIOStreams host already serves), auto-copies it, shows the in-app Add Account steps, and links the official Manifest Merger, Feed Editor and Validator for adding curated TMDB/Trakt feeds. A P2P build with the Chillio target is blocked before anything is posted: the ChillLink protocol carries direct HTTP, Usenet, debrid and live URLs only, so a torrent build would install but play nothing — the Stremio target stays available for P2P.
  </Card>
  <Card title="Community addon directory linked" icon="bolt">
    the Tools hub now points at stremio-addons.net (community-moderated, external), and the Best Add-ons guide cites per-addon directory pages with an honest note that the catalog includes adult addons and does not accept the preconfigured manifests this configurator produces. A weekly advisory workflow now diffs that directory’s approved AIOStreams instances against the audited host registry and opens an issue when a new public host appears.
  </Card>
  <Card title="Generated output unchanged" icon="shield-check">
    every config the configurator and the CLI build is byte-for-byte what 3.23 produced apart from the version stamp; only the version stamp moves.
  </Card>
</CardGroup>
