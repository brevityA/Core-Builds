# What's New in the Configurator

This page is regenerated from `configurator/src/data/changelog.js` by `scripts/sync-docs.py`, so it always reflects the latest shipped configurator version (currently **v3.49**).

For the template-suite release log, see the [Changelog](https://core-builds.mintlify.app/changelog).

## Configurator v3.49 (Nov 26 2026)

<CardGroup cols={2}>
  <Card title="Full stack now sets AIOMetadata up properly" icon="sparkles">
    Quick install used to add AIOMetadata's bare address, which has no settings and so shows no rows, no search and no details. It now creates an AIOMetadata config on the public ElfHosted instance with its own default providers, protected by the same password as your AIOStreams config, and installs that. An empty AIOMetadata from an earlier install is swapped out; one you set up yourself is kept.
  </Card>
  <Card title="The Cinemeta patch works again" icon="bolt">
    it went to a Cinebye address that no longer exists, so Cinemeta was never patched. Full stack now hides Cinemeta's home rows and search in your Stremio account itself, from your browser. Cinemeta still supplies details, notifications and the calendar.
  </Card>
  <Card title="Cinemeta is only patched once AIOMetadata is in place" icon="shield-check">
    if AIOMetadata cannot be set up, Cinemeta is left as it is, so your home screen and search never end up empty.
  </Card>
  <Card title="Generated output unchanged" icon="sliders">
    every reference config is byte-for-byte what 3.48 produced apart from the version stamp. This release changes what Full stack does on your Stremio account, not the AIOStreams config.
  </Card>
</CardGroup>

## Configurator v3.48 (Nov 26 2026)

<CardGroup cols={2}>
  <Card title="Ready to play first replaces hard cached-only" icon="sparkles">
    3.47 made Quick install's Balanced hide every stream your service would still have to download. AIOStreams removes those even when nothing else is left, so a brand-new episode or a rarer title could show no streams at all (checked in AIOStreams 2.36.0). Fast and Balanced now show only streams that play straight away while there are any, and the ones that need downloading when there are none, among streams that pass your other settings such as picture quality.
  </Card>
  <Card title="Fast behaves the same way" icon="bolt">
    Fast hid uncached streams outright before 3.48 too; it now uses Ready to play first as well.
  </Card>
  <Card title="Ready first is also in the full builder" icon="shield-check">
    Streams shown offers Mixed, Ready first, Cached only and Uncached only, and the CLI takes --cache-mode ready. Cached only still hides downloads even when nothing else is ready.
  </Card>
  <Card title="A Cached only pick from 3.47 is explained" icon="sliders">
    if you chose Cached only in Quick install, it is kept and the screen says what it does; choose Ready to play to switch.
  </Card>
  <Card title="Checked in a real AIOStreams on every save test" icon="gauge">
    a stub add-on serves cached and uncached streams, and the Quick install config must list only cached ones while any exist and the uncached ones when none do, ; both host variants check that these configs save, and the open variant also checks the streams that come back.
  </Card>
  <Card title="Generated output changes for Ready to play first only" icon="wand">
    new Quick installs on Fast and Balanced carry one extra exclude rule and excludeUncached off; two new reference configs pin that. Every other reference config is unchanged apart from the version stamp.
  </Card>
</CardGroup>

## Configurator v3.47 (Nov 26 2026)

<CardGroup cols={2}>
  <Card title="Quick install's Balanced shows only streams that play straight away" icon="sparkles">

  <Card title="Your own Streams shown pick is kept" icon="bolt">

  </Card>
  <Card title="Clearer Cached only label" icon="shield-check">
    it now reads 'Plays straight away — anything still downloading is hidden' instead of promising instant play.
  </Card>
  <Card title="Generated output unchanged" icon="sliders">
    every reference config is byte-for-byte what 3.46 produced apart from the version stamp. Only a new Quick install on Balanced differs: it carries excludeUncached, which Fast already did.
  </Card>
</CardGroup>
