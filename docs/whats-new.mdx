# Configurator v2.78 (July 22, 2026)

Version **2.78** moves the configurator from a single hand-maintained source file to a modular, tested package while preserving a downloadable standalone `configurator/index.html` release.

## Quick Install improvements

- Multi-provider selection remains supported.
- Paid provider fields now include **Get key**, **Open account**, or **Open dashboard** links.
- StreamNZB displays manifest guidance rather than a nonexistent central key page.
- An expandable **TMDB metadata — optional** section accepts either a Read Access Token or API Key.
- Missing TMDB credentials produce a clear warning because title/year matching will be disabled; users may still continue.
- Optional services and scrapers stay in a compact picker instead of crowding the main flow.

## Host selection

Automatic selection remembers the last successful host, prefers stable instances running AIOStreams `2.31.1` or newer, respects provider restrictions, and uses nightly infrastructure only as a fallback. Legacy or incompatible instances are skipped automatically.

## Device corrections

Device capabilities are centralized and conservative:

- Apple TV 4K A15 is not treated as hardware-AV1 capable.
- Apple TV is not described as bitstreaming TrueHD or DTS-HD; compatible apps may decode supported formats to multichannel PCM.
- Chromecast with Google TV 4K and HD are treated as separate models for AV1 support.
- Nvidia Shield 2019 retains Dolby Vision and lossless-audio passthrough support, but not AV1.
- Internal TV apps and unknown devices no longer assume lossless-audio passthrough.
- ONN profiles do not assume Dolby Vision across every model.

## Schema compatibility

The final schema guard maps known legacy enum names, trims values, removes unsupported entries, deduplicates arrays, and adds safe defaults. This prevents old values such as `audio`, `language`, `release_group`, `debrid`, or `nzb` from reaching current AIOStreams enum fields unchanged.

## Privacy wording

Core Builds now describes each path precisely:

- **Export JSON:** creates the configuration locally in the browser.
- **Direct Install:** sends the generated configuration to the selected AIOStreams host.
- **Direct Stremio installation:** sends the supplied Stremio login details to the Stremio API for that operation.

Credentials are not included in sanitized diagnostics. Core Builds does not use “zero-knowledge” or “no data is sent anywhere” claims.

## Interface and community

- The central Core gem remains the support control and visibly pulses/glows.
- The live usage counter remains enabled.
- Community links use the visible name **Core Crew** and point to `r/CoreBuilds`.
- Light mode uses readable pale selected surfaces rather than inheriting dark gradients.
