## RB3 — Auburn Tiger Edition

**Author:** RB3 · **Services:** TorBox Pro + Real-Debrid · **Resolution:** 4K + 1080p

A performance-focused dual-service build engineered for power users. TorBox Pro handles primary Usenet-priority streaming; Real-Debrid fills gaps as a secondary cache. Named for the Auburn Tigers colour palette — orange and navy resolution badges throughout.

**Highlights:**
- Usenet supremacy PSE — cached TorBox Usenet results forced to the absolute top
- 100 GB file size limits, 250 Mbps uncapped bitrate ceiling
- Full premium A/V: Dolby Vision, HDR10+, IMAX, Atmos/TrueHD/DTS:X preferred
- Aggressive deduplication across dual-service results
- Custom Auburn Tiger formatter — warm high-contrast orange/navy visual language

## RB3 — TorBox Pro + RD Hybrid

**Author:** RB3 · **Services:** TorBox Pro + Real-Debrid · **Resolution:** 4K

Dual-service template built on the SEL framework v2.6.1. Prioritises cached TorBox Usenet releases with Real-Debrid as seamless fallback. Includes SeaDex, Meteor, Comet, Torrentio, Knaben, Newznab (TorBox Search), and STorz.

**Highlights:**
- SEL PSEs/ESEs/ISEs (live-synced)
- Vidhin's ranked regex patterns for release group scoring
- AutoPlay configured for both Stremio and WuPlay (no Cinemeta required)
- Smart language detection — multilingual tracks displayed as `🗣️ MULTI`

## MightyIcyy — Prism

**Author:** MightyIcyy · **Services:** TorBox Essential · **Resolution:** 1080p · **Version:** 1.0.0

A clean, no-fuss 1080p build for TorBox Essential subscribers. Targets WEB-DL, BluRay, and WEBRip — no REMUX, no 4K. Built for simplicity and fast cached playback without a complex addon stack.

**Highlights:**
- WEB-DL → BluRay → WEBRip quality priority
- 4K and REMUX hard-excluded
- English preferred, Russian/Ukrainian excluded
- AutoPlay on `matchingFile` (resolution + quality + release group)
- Torrentio + Debridio scraper stack
- File size limits: movies 800 MB–15 GB, episodes 300 MB–8 GB

## Community Formatters

## Submit a Community Template

Open a pull request to [`Community-Templates/`](https://github.com/brevityA/Core-Builds/tree/main/Community-Templates) in the GitHub repository. Include:

- Your template JSON file
- A `README.md` with author, services required, resolution, and what makes it different
- A banner SVG (optional but encouraged — match the 1200×280 format from `Assets/`)
